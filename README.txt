THAR TALEEM & CAREER RAAH — DISTRICT THARPARKAR PROJECT (UPGRADED)

IMPORTANT: This is an upgrade of the existing district-wide project. The original page sections, guidance, scholarship and university information, solutions, report templates, and survey questions have been preserved. New features have been added without replacing the site's original green design.

RUN
1. Extract this ZIP.
2. Open index.html in Chrome or Edge.
3. Internet connection is needed for Chart.js, Excel parsing (SheetJS), and remote Wikimedia Commons images.
4. Use the “Dark mode” button in the navigation to switch themes.

NEW FEATURES
- Light/dark mode toggle; preference is stored in this browser.
- Tharparkar photo/culture gallery with captions and source links.
- Excel (.xlsx/.xls) and CSV upload in the dashboard.
- Automatic response counts, option counts, percentages, multi-select question analysis, taluka/area breakdown, and charts for recognized survey columns.
- Download aggregate analysis as CSV.
- “Original survey par wapas” restores the bundled anonymized snapshot.
- The analysis runs in the browser. It does not send uploaded rows to a project server.
- Timestamps, email addresses, personal identifiers and free-text answers are not displayed in the dashboard or exported aggregate report.
- The live Google Form link is configured in index.html.

CURRENT DATA
The bundled `survey_results.json` and default dashboard are based on an anonymized aggregate of 19 survey responses collected in October 2026. It contains counts only; no respondent-level rows, timestamps, emails or free-text comments are included.

DATA ANALYSIS NOTES
- Upload the Google Forms response export in Excel or CSV format.
- The first worksheet is read. The first row must contain column headers.
- Numbered survey questions are recognized; multiple-select options are split and counted separately.
- Free-text question 16 and the consent question are excluded from chart output to reduce privacy risks.
- For custom survey files, generic question charts are still shown where a column can be summarized. Main dashboard cards work best with the Thar Taleem question headers.
- Percentages are calculated against the uploaded response rows. In multi-select questions, totals can exceed 100% because respondents may choose several options.
- Small or uneven samples do not represent all of District Tharparkar. Always state sample size, dates and taluka coverage.

PHOTO NOTES
The gallery includes Tharparkar landscape, traditional clothing, local life, traditional hamlets, community learning and cultural heritage imagery. Captions and source links are included. The community-learning image is not claimed to be a photo of a specific school building. For fieldwork photos of actual schools, obtain permission and verify the location before publishing.

PRIVACY AND RESEARCH INTEGRITY
Participation should be voluntary. Avoid collecting names, phone numbers, CNIC numbers and exact home addresses. Do not describe a small convenience sample as a representative district-wide survey. Confirm local school facts with current records and consent before publishing.
